## Таблица свойств. Компонент Button (Кнопка)

<details>
  <summary>Пример использования кнопки в React</summary><br>

```JSX
// Кнопка типа "primary" с обработкой состояния loading (загрузка)
<Button kind="primary" vertSize="40" loading loadingMessage="Проверяем данные">Продолжить</Button>
```

</details>

### Таблица свойств

| Свойство         | Описание                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `active`         | `boolean`<br> Позволяет управлять `active`-состоянием кнопки.<br>По умолчанию: `-`           |
| `after`          | Контент, отображаемый после основного содержимого кнопки.<br>По умолчанию: `-`               |
| `align`          | Выравнивание основного содержимого кнопки.<br> По умолчанию: `center`                        |
| `before`         | Контент, отображаемый перед основным содержимым кнопки.<br>По умолчанию: `-`                 |
| `disable`        | `boolean`<br> Позволяет управлять `disable`-состоянием кнопки.<br>По умолчанию: `-`          |
| `enabled`        | `boolean`<br>Позволяет управлять `enabled`-состоянием кнопки. <br>По умолчанию: `-`          |
| `hover`          | `boolean`<br>Позволяет управлять `hover`-состоянием кнопки. <br>По умолчанию: `-`            |
| `kind`           | `primary \| secondary \| tertiary  \| borderless`<br>Задает тип кнопки.<br>По умолчанию: `-` |
| `loading`        | `boolean`<br>Позволяет управлять `loading`-состоянием кнопки. <br>По умолчанию: `-`          |
| `loadingMassage` | `string`<br>Задает основное содержимое кнопки в `loading`-состоянии. <br>По умолчанию: `-`   |
| `pressed`        | `boolean`<br>Позволяет управлять `pressed`-состоянием кнопки. <br>По умолчанию: `-`          |
| `size`           | `small \| medium \| large`<br>Задает размер кнопки.<br>По умолчанию: `-`                     |
| `vertSize`       | Задает вертикальный размер кнопки.<br>По умолчанию: `-`                                      |
