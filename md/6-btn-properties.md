## Таблица свойств. Компонент Button (Кнопка)

<details>
  <summary>Пример использования кнопки в React</summary><br>

```JSX
// Кнопка типа "primary" с обработкой состояния loading (загрузка)
<Button kind="primary" vertSize="40" loading loadingMessage="Проверяем данные">Продолжить</Button>
```

</details>

### Таблица свойств

| Свойство         | Описание                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `active`         | `boolean`<br> Управляет `active`-состоянием кнопки.<br>По умолчанию: `-`                     |
| `after`          | Отображает контент после основного содержимого кнопки.<br>По умолчанию: `-`                  |
| `align`          | Выравнивает основное содержимое кнопки.<br> По умолчанию: `center`                           |
| `before`         | Отображает контент перед основным содержимым кнопки.<br>По умолчанию: `-`                    |
| `disable`        | `boolean`<br>Управляет `disable`-состоянием кнопки.<br>По умолчанию: `-`                     |
| `enabled`        | `boolean`<br>Управляет `enabled`-состоянием кнопки. <br>По умолчанию: `-`                    |
| `hover`          | `boolean`<br>Управляет `hover`-состоянием кнопки. <br>По умолчанию: `-`                      |
| `kind`           | `primary \| secondary \| tertiary  \| borderless`<br>Задает тип кнопки.<br>По умолчанию: `-` |
| `loading`        | `boolean`<br>Управляет `loading`-состоянием кнопки. <br>По умолчанию: `-`                    |
| `loadingMassage` | `string`<br>Задает основное содержимое кнопки в `loading`-состоянии. <br>По умолчанию: `-`   |
| `pressed`        | `boolean`<br>Управляет `pressed`-состоянием кнопки. <br>По умолчанию: `-`                    |
| `size`           | `small \| medium \| large`<br>Задает размер кнопки.<br>По умолчанию: `-`                     |
| `vertSize`       | Задает вертикальный размер кнопки.<br>По умолчанию: `-`                                      |
