## Предложения по дополнению описания компонента

1. [Стартовая страница](../README_Buttons.md "Корневой файл ReadMe_Buttons.md") получила название «Кнопки» для обеспечения модульного редактирования описания или дополнения новыми компонентами, например,«Группы кнопок» (Button Groups), «Плавающие кнопки действия» (FABs, Floating action buttons) и др.
   Такая компоновка описания будет удобна при масштабировании дизайн-системы под проекты.

2. На [стартовой странице](../README_Buttons.md "Корневой файл ReadMe_Buttons.md") добавил бы переход (кнопку или ссылку) на ресурсы с набором компонентов пользовательского интерфейса в одном из популярных сервисов (Figma, Flutter, Jetpack Compose, Android Views и др.), если предполагается публичность дизайн-системы. При ограниченном доступе к системе добавил бы ссылку на доверенный сервис с авторизацией.

3. В разделе [Обзор](/md/1-btn-overview.md) для уточнения постановки задания:
   - Необходимо взаимодействие с разработчиком:
     - Не хватает информации по правилам использования тега `<a>` c атрибутом `href`, который часто выступает альтернативой для тега `<button>`. Информацию можно добавить в виде примечания. Также можно упомянуть про работу с кнопками `<input>` c типом `submit`, `button`, `reset`, если это важно.
     - Не хватает примеров кода с атрибутом для задания размера кнопок `small`, `medium`, `large`. При этом в задании в коде задан пользовательский атрибут с размером: `vertSize="40"`.
     - Раздел [Таблица свойств](/md/6-btn-properties.md) необходимо дополнить значениями по умолчанию. Дополнительно можно добавить таблицу методов.
   - Необходимо взаимодействие с дизайнером по макету:
     - Не представлен макет конфигурации кнопок c размерами: `small`, `medium`, `large`.
     - Не указано для какого размера кнопок приведен макет в ТЗ.
     - Не представлены кнопки в статусе Загрузки (loading). При этом приведены кнопки с неучтенными состояниями: Focused, Pressed Focused / Active / Hovered.
     - Не представлены макеты кнопок с иконкой или бейджем слева или справа от текста, их особенностями: залитые (solid) или линейные (line), размерами и вариантами мастабирования, например, 16px и 12px / 20px / 24px и т.д.
     - Не представлены макеты кнопок для светлой и тёмной тем.
     - Не хватает стандартных цветовых решений для всех типов кнопок:
       - акцентный цвет, зависимый от светлой или тёмной схем;
       - акцентный цвет, независимый от светлой или тёмной схем;
       - зеленый цвет (цвет для действия подтверждения, независимый от схем);
       - красный цвет (цвет критических действий, независимый от схем);
       - нейтральный цвет (альтернативный акцентным цветам, зависимый от схем);
       - специальный цвет (для размещения поверх фото и цветных элементов, независимый от схем).
